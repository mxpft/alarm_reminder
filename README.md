# LittleButler

**产品名：** LittleButler
**描述：** YOUR PERSONAL MEMORY BUTLER
**slogan：** Never Miss a Day. Never Lose a Memory.
**中文宣传语：** 不错过重要的日子，不遗失值得珍藏的记忆。

---

## 一、产品概述

LittleButler 是一款本地优先的个人记忆助手 App，集成生日提醒、密码管理、一句话日记三大功能模块。所有数据只存在本机，不上云、无后端。

**技术栈：** Flutter 3.47.8 / Hive 本地数据库 / flutter_local_notifications / android_alarm_manager_plus / device_calendar_plus / lunar 农历转换

---

## 二、页面结构

### 1. 主页（HomePage）

打开 App 后的首屏，白色/浅蓝背景（#F8F9FF）。

**顶部问候区：**
- 左侧："你好\nLittleButler"（28px粗体）+ 副标题"不错过重要的日子，不遗失值得珍藏的记忆"（去掉句号，字号缩小一行显示）
- 右上角：圆形头像（assets/little-butter-2.png）

**三个功能卡片（垂直居中，高度24px padding）：**

| 卡片 | 图标 | 副标题 | 点击行为 |
|------|------|--------|----------|
| 生日提醒 | cake_rounded（蓝色底#D8E2FF） | 记录亲友生辰与生肖 | 进入生日提醒页 |
| 密码管理 | lock_rounded（蓝色底#D8E2FF） | 已托管 X 个账号密码（实时更新） | 进入密码管理页 |
| 一句话日记 | edit_note_rounded（紫色底#E3DFFF） | 来说说今天发生了什么 | 进入一句话日记页 |

**生日提醒卡片"今天"tag：**
- 实时计算今天是否有人过生日
- 有则显示粉色"今天"标签
- 每次进入 App、修改生日数据后自动重算

### 2. 生日提醒页

**顶部固定头部（滚动时不动）：**
- 左上角返回按钮（回到主页）
- 两个测试按钮：铃铛=测试即时通知、时钟=测试定时通知
- 空数据时也显示这两个按钮

**卡片列表（按距离下一次生日剩余天数排序）：**

每个卡片包含：
- 左侧渐变竖线（仅今天过生日时显示，粉色渐变）
- 第一行：姓名（16px粗体）+ 生肖emoji徽章（灰底）+ 年龄徽章（黄底）
- 第二行：日历图标 + "公历/农历 · 录入的原始生日日期"
- 第三行：备注（上方有分隔线，全量显示，卡片高度随备注自适应）
- 状态标签：本月过生日的人才显示倒计时tag（"今天"/"还有X天"），不在本月的不显示

**交互：**
- 单击卡片：编辑生日
- 长按卡片：弹出删除确认弹窗（无标题，"删除"按钮纯文字红色，无背景色）
- 空状态：蛋糕图标 + "还没有生日记录" + "点击右下角按钮，开始添加第一个生日"，水平垂直居中

**权限引导弹窗：**
- 首次进入时弹出"为确保提醒准时送达"
- 点击"知道了"后不再弹出（存在 Hive settings box，key: permission_hint_shown）

### 3. 新增/编辑生日弹窗

**标题：** 新增生日 / 编辑生日（18px正常大小）

**表单字段顺序：**
1. 姓名（必填，占位符"请输入姓名"）
2. 公历/农历单选
3. 出生日期（滚轮式三列：年/月/日，和农历选择器风格一致）
4. 提醒时间（滚轮式上下滑动：小时0-23，分钟0-59，无AM/PM切换）
5. 备注（选填，表单最后一项）

**样式：**
- 所有输入框、日期选择框都有浅灰色（#E2E8F0）实体border
- 取消按钮：OutlinedButton 带border
- 保存按钮：蓝色实心
- 选完头像/日期/时间后不自动弹出键盘（只有点击输入框才弹键盘）

### 4. 密码管理页

**顶部固定区域：**
- 返回按钮
- 密码库摘要卡片：锁图标（蓝底）+ "密码库" + "已安全保管 X 个账号凭证" + 蓝色"新建"按钮
- 搜索框：有数据时才显示，实时过滤应用名和用户名，无防抖，清空时显示全部

**密码卡片列表：**

每个卡片包含：
- 标题（16px粗体）
- 用户名行：标签"账号 / 用户名" + 值 + 右侧复制按钮
- 密码行：标签"登录密码" + 值（等宽字体）+ 右侧复制按钮
- 备注（如有）：上方分隔线 + 备注文字

**交互：**
- 单击卡片：编辑密码
- 长按卡片：弹出删除确认弹窗（样式同生日页）
- 点击复制按钮：复制到系统剪贴板，提示"账号复制成功"/"密码复制成功"
- 空状态：大圆形lock图标（浅蓝底）+ 右下角小圆形vpn_key图标 + "密码库还是空的" + 描述文字

### 5. 新增/编辑密码弹窗

**标题：** 添加新密码 / 编辑密码（无左侧icon）

**表单字段：**
1. 平台名称（必填，占位符"请输入应用名称"，带language icon）
2. 账号或邮箱（必填，占位符"输入账号名称或邮箱"，带person icon）
3. 安全密码（必填，右侧有随机生成密码按钮auto_fix_high，点击生成8位含大小写字母+数字+特殊字符的密码）
4. 备注信息（可选）

**样式：**
- 所有输入框带浅灰色（#E2E8F0）实体border
- 取消按钮：OutlinedButton 带border
- 保存按钮：蓝色实心

## 三、数据存储（Hive 本地数据库）

| Box 名称 | 内容 | TypeAdapter |
|-----------|------|-------------|
| birthdays | 生日记录 | BirthdayEntryAdapter (typeId=0) |
| passwords | 密码记录 | PasswordEntryAdapter (typeId=1) |
| settings | 系统设置（权限引导标志位） | 直接读写 |

**生日记录字段：**
id、name、remark、type（公历/农历）、year、month、day、isLeap（闰月）、remindHour、remindMinute、avatarPath、calendarEventId

**密码记录字段：**
id、title、username、password、note

## 四、通知与提醒

**技术方案：** android_alarm_manager_plus + flutter_local_notifications

- 通知通道ID：birthday_channel
- 通知图标：@mipmap/ic_launcher
- App每次打开：自动重新调度所有通知（解决农历跨年、手机重启丢失问题）
- 新增/修改/删除生日：立刻重新调度
- 测试按钮：铃铛=测试即时通知、时钟=测试定时通知

---

## 五、日历同步

- 插件：device_calendar_plus: ^0.12.0
- 新建生日时自动写入系统日历
- 编辑/删除生日时同步更新日历事件
- 小米手机：需授予日历权限

---

## 六、头像

- 支持从相册选择并裁剪
- 存储路径：App文档目录/avatars/（getApplicationDocumentsDirectory()）
- 不存系统临时目录（避免被系统清理）

---

## 七、平台限制（安卓）

1. 小米/华为等定制系统：需手动设置省电策略→无限制、允许自启动、授予精确闹钟权限
2. 手机重启后闹钟丢失，依赖开机自启恢复调度
3. 用户手动上滑彻底清除App进程 → 系统清空闹钟（厂商电源策略，无法突破）
